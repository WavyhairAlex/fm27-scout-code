## 1. 本轮完成

### 1.1 合同、市场、置信度和伤病筛选

Value Finder 和 Stats Moneyball 现在都支持：

- `contract_end_before`：合同到期早于指定日期；
- `listings`：挂牌出售 / 挂牌出租 / 自由身；
- `min_confidence`：最低置信度；
- `exclude_injured`：排除当前受伤球员；
- `exclude_injury_history`：排除有伤病史的球员。

Stats tab 的本地保存视图会一并保存这些条件。旧视图缺少新字段时按默认值加载。

覆盖测试：

- `moneyball::tests::injury_filters_exclude_unavailable_players`
- `stats_moneyball::tests::injury_filters_exclude_unavailable_players`
- 全量 `cargo test --workspace`：核心 76 个单元测试通过。

### 1.3 npxG A/B

在 `BB KING - Parma Calcio.fm` 上，用参考实现重建 core 模型，只把 ST/AM 的 xG/90 替换为 npxG/90：

- 参与评分：19,582 人（两种模型相同）。
- `production_tier` top 50 重叠：46/50。
- `surplus_tier` top 50 重叠：50/50。
- 分位置 `production_tier` top 50：ST 48/50，AM 48/50。

结论：

- npxG 会改变少量生产排名，但对成本调整后的最终榜单几乎没有影响。
- 目前没有足够的结果数据证明 npxG 更好，因此不切换默认模型；`non_penalty_expected_goals` 已解析入库，可继续用于后续实验。

### 1.4 权重 ±20% 敏感性

在 Parma 存档上，对 core 模型每个位置的每个指标单独做 ±20% 扰动，再比较该位置 top 50 重叠：

| 位置 | 最小重叠 | 最大重叠 |
|---|---:|---:|
| ST | 47/50 | 50/50 |
| AM | 46/50 | 50/50 |
| MID | 47/50 | 49/50 |
| DC | 41/50 | 46/50 |
| FB | 43/50 | 47/50 |

结论：

- ST/AM/MID 对单项权重扰动较稳定。
- DC/FB 对抢断、传球完成率等单项权重更敏感，符合这两个位置 core 指标较弱的已知限制。
- 暂不调整权重；UI 应继续显示置信度和样本量，DC/FB 的推荐措辞应更保守。
